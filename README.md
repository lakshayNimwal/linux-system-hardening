# 🛡️ Linux System Hardening Guide

Step-by-step scripts and documentation to secure a Linux server, covering user policies, SSH hardening, firewall, auditd, and essential security tools. Ideal for security analysts, DevSecOps, and ethical hackers.

## 📋 Table of Contents
1. Basic Security
2. SSH Hardening
3. Firewall Setup
4. Log Monitoring & Auditing
5. Filesystem & Kernel Hardening
6. Security Tools

## ✅ Prerequisites
- Basic Linux knowledge
- Access to a test Linux VM (Ubuntu or CentOS recommended)

## 🧱 1. Basic Security
Includes password policy hardening using login.defs and PAM.

## 🔐 2. SSH Hardening
Disables root login, enforces key-based authentication, and changes SSH port.

## 🔥 3. Firewall Setup
UFW or firewalld configuration to allow only required ports.

## 📜 4. Log Monitoring & Auditing
Using auditd and logwatch to monitor changes and access.

## 💽 5. Filesystem & Kernel Hardening
Hardening /tmp and tuning sysctl parameters.

## 🛠️ 6. Security Tools
Tools like Lynis for auditing and AIDE for integrity checking.
